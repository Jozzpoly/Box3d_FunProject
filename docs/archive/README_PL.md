# Archiwum dokumentacji JV

Pliki w tym katalogu są zachowane jako historia decyzji, dowody pochodzenia i
materiał dziedzictwa. **Nie są bieżącymi instrukcjami.** Aktualny start:
`../JV_DOCS_INDEX_PL.md`.

## Struktura

- `vehicle_legacy_2026-07/` — zamknięte milestone, audyty, refaktory, finalizacja
  nadwozia/rigu i dawna roadmapa;
- `map_scan_2026-07/` — roadmapy mapy, etapy E1–E6, audyty i fundament skanu;
- `wheels/` — handoffy oraz dawne dzienniki iteracji, które doprowadziły do obecnego `b3Wheel`;
- `jes_foundation_2026-07-15/` — historyczny pakiet założycielski JES;
- `ledgers/` — poprzednie wersje state/checkpoints/debt;
- `consolidated_2026-08/` — aktywne wcześniej dokumenty scalone w konkursowej rekurencji;
- pozostałe pliki — wcześniejsze raporty M0–M5 i handoffy agentowe.

## Jak korzystać

1. Zacznij od bieżącego indeksu, nie od wyszukiwarki po archiwum.
2. Użyj archiwum, gdy potrzebujesz uzasadnienia dawnej decyzji lub surowej
   historii problemu.
3. Nie kopiuj statusu `TODO`, `active` ani nazwy starej gałęzi do nowego planu.
4. Gdy archiwalny dokument przeczy kodowi lub bieżącemu state, wygrywa kod i
   `../CURRENT_STATE_INDEX_PL.md`.
5. Historyczne ścieżki zapisane w treści mogą wskazywać dawne położenie pliku;
   są częścią snapshotu, nie aktywnym linkiem.
